# Orbit: A Chatbot About the Solar System and Space Missions

Orbit is a conversational assistant that answers questions about the solar system and space missions, in both Spanish and English. It employs Retrieval-Augmented Generation (RAG) for each query: it retrieves the most relevant excerpts from a knowledge base compiled from public NASA and Wikipedia pages processes them using an open-source language model, and provides the sources for its answers.

The entire system is built using free, open-source technology:

| Component | Choice |
|---|---|
| Language Model | `Qwen/Qwen2.5-1.5B-Instruct` (local execution); `Qwen/Qwen2.5-0.5B-Instruct` (cloud-based demo, via Hugging Face Transformers) |
| Embedding Model | `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` |
| Vector Database | ChromaDB (persistent, stored in `data/chroma`) |
| Interface | Streamlit |
| Hosting | Streamlit Community Cloud (free) |

## Features

- Multi-turn conversations with short-term memory (capable of understanding follow-up questions).
- Source citation for every answer (titles and URLs extracted from the retrieved excerpts; not generated by the model).
- Safety protocols: Rejects requests for real-time data and attempts at prompt injection; if no relevant information is found, it states "no reliable information available" rather than attempting to guess.
- Response modes: "explain simply," "compare," and "quiz."
- Interface available in Spanish and English, featuring an overview of its capabilities and limitations, suggested questions, and a feedback system (👍/👎).

## Local Execution

Requirements: Python 3.11 and approximately 8 GB of free RAM (the 1.5B model requires about 6 GB if running on the CPU).

#1. Create an isolated environment (using `conda` in this example; `venv` also works)
conda create -n orbit python=3.11 -y
conda activate orbit

#2. Install dependencies
pip install -r requirements.txt

#3. Launch the application from the project folder
streamlit run app.py
```

The first time you run it, the models will be downloaded from Hugging Face (approximately 3.5 GB in total), which may take several minutes.
Access <http://localhost:8501>. When using the CPU, generating a response may take between 30 and 110 seconds.
To test the *backend* without the interface, run: `python orbit_core.py`.

### Configuration

All parameters are located in `config.yaml`, each with a corresponding comment. Some values ​​can also be modified using environment variables:

| Variable | Overrides | Example |
|---|---|---|
| `ORBIT_LLM_NAME` | `models.llm_name` | `Qwen/Qwen2.5-0.5B-Instruct` |
| `ORBIT_LLM_DTYPE` | `models.llm_dtype` | `bfloat16`, `float32` |
| `ORBIT_DEVICE` | `models.device` | `cpu` |
| `ORBIT_MAX_NEW_TOKENS` | `generation.max_new_tokens` | `200` | Other useful settings include: `generation.temperature`, `retrieval.top_k`, `retrieval.min_similarity`, `memory.max_turns`, and the `ui` section (which contains all the text that appears in the interface, in both Spanish and English). To enable the feedback form button, configure `ui.feedback_form_url`.

## Known Limitations

- A small language model may make errors, even when citing its sources (for example, it might incorrectly translate the English term "billion" into Spanish).
- The knowledge base covers only the NASA and Wikipedia pages that have been loaded.
- It does not have access to real-time data.
- Free, CPU-based hosting is slow and has limited memory; therefore, the cloud-based demo uses a smaller model than the local version.
- Logs generated by the cloud application are not persistent.
